# 12-Month Engineering Roadmap

## Objective

Establish a credible flagship UAV/UAS portfolio by shipping high-quality architecture, simulation, autonomy, hardware, and mission-system repositories in a staged sequence.

## Q1 — Foundation

- Finalize profile and architecture narrative
- Publish engineering standards and contribution governance
- Create templates for issues, PRs, releases, and security handling
- Define maturity-state policy and evidence requirements

## Q2 — Core Systems

- Stand up PX4 + ROS 2 integration baseline
- Build simulation-first workflow (SITL + Gazebo)
- Publish initial hardware architecture docs:
  - system requirements
  - interface-control baseline
  - power and mass budget drafts

## Q3 — AI + Mission Platforms

- Deliver edge-AI perception baseline with reproducible evaluation workflow
- Deliver mission-control core service architecture and APIs
- Deliver drone data ingestion and analytics pipeline baseline

## Q4 — Validation + Portfolio Hardening

- Add HITL-oriented validation strategy where practical
- Add cross-repo quality gates and release cadence
- Publish case studies and engineering limitations
- Perform technical portfolio audit and reprioritize next-year roadmap

## Success Metrics (Portfolio Level)

- 10 flagship repositories with complete baseline documentation
- All flagship repos include security policy, contribution guide, roadmap, and changelog
- Simulation-first workflow documented for autonomy features
- No unsupported claims of capability, certification, or production status

# HDCS Repository Templates

Use these templates to standardize project documentation quality across the HDCS ecosystem.

- `README_TEMPLATE_UAV_PROJECT.md`
- `README_TEMPLATE_AI_ML_PROJECT.md`
- `README_TEMPLATE_ROS2_PROJECT.md`
- `README_TEMPLATE_PYTHON_PROJECT.md`
- `README_TEMPLATE_RESEARCH_PROJECT.md`

Each template is designed to enforce:

- clear scope and maturity labeling
- reproducibility guidance
- security and safety disclosure
- consistent engineering structure

# Security Policy

## Scope

This repository contains architecture and engineering artifacts for UAV/UAS systems. Security observations related to code, workflows, dependencies, or sensitive documentation are in scope.

## Reporting a Vulnerability

Please report vulnerabilities privately to the repository maintainers. Include:

- affected file/component
- impact summary
- reproduction details (if applicable)
- suggested mitigation

Do not publish sensitive details in public issues before triage.

## Security Baseline

- No secrets or credentials committed to the repository
- Least-privilege access for maintainers and automation
- Dependency and workflow review for new integrations
- Clear threat boundaries in architecture documentation

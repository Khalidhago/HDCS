# Contributing to HDCS

First off, thank you for considering contributing to Hago Drone Consulting Services (HDCS). We welcome contributions from everyone.

## Development Process

1. **Fork** the repo on GitHub
2. **Clone** the project to your own machine
3. **Commit** changes to your own branch
4. **Push** your work back up to your fork
5. Submit a **Pull Request** so that we can review your changes

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

## Coding Guidelines

- We use `clang-format` for C++
- We use `black` and `flake8` for Python
- We use `golangci-lint` for Go
- Please make sure all CI checks pass before submitting a Pull Request.

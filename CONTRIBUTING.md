# Contributing to HDCS

Thank you for contributing to Hago Drone Consulting Services (HDCS).

## Contribution Scope

This repository is the HDCS ecosystem hub. Contributions should focus on:

- Architecture documentation
- Governance and standards
- Portfolio structure and roadmap
- Reusable project templates

## Workflow

1. Open an issue describing the problem or proposal.
2. Create a focused branch.
3. Submit a pull request with:
   - clear scope
   - rationale
   - impacted files
   - follow-up actions (if any)

## Quality Expectations

- Keep claims technically accurate and verifiable.
- Use explicit maturity labels when introducing project references.
- Avoid marketing-only content.
- Keep changes non-destructive unless explicitly approved.

## Documentation Standards

- Prefer concise, structured sections.
- Use consistent UAV/UAS engineering terminology.
- Distinguish flight-critical vs mission/AI/ground/cloud systems.
- Include assumptions and limitations when relevant.

## Commit and PR Guidance

- Keep changes atomic and reviewable.
- Use descriptive commit messages.
- Link issues in pull requests when applicable.

## Code of Conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
